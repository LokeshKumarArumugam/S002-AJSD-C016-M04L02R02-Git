NOTE: Git Commands:
===========================================
1. Clone the project using HTTPS or SSH: 
	git clone https://github.com/LokeshKumarArumugam/S002-AJSD-C016-M04L02R02-Git.git
	git clone git@github.com:LokeshKumarArumugam/S002-AJSD-C016-M04L02R02-Git.git
2. Create a new Branch from the cloned repository: 
	git branch release0.0.1
	git push origin release0.0.1
	git checkout release0.0.1
	git checkout -b release0.0.1
	git switch origin
	git switch release0.0.1
	git branch -m release0.0.1 release0.0.2
	git branch -D release0.0.1
	git branch -d release0.0.1
3. Add and Commit the files in the cloned repository: 
	git status
	git add _/git-commands.txt
	git status
	git commit -m "Added a new git-commands.txt file under '_/' directory"
	git status
	git revert HEAD
4. Restore a staged files in the clone repository:
	git restore --staged _/git-commands.txt
5. Push and pull request from the clone repository: 
	git remote -v
	git pull origin release0.0.1
	git push origin
